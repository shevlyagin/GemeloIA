# GemeloIA

GemeloIA is an AI-powered digital twin assistant integrated with Telegram. The project is being developed as part of a Higher Vocational Training programme in Multiplatform Application Development (DAM).

The assistant is designed to collect and organize information about the user's habits, food, emotional state, interests and personal goals in order to generate increasingly personalized recommendations over time.

## Planned stack

- Go (Golang)
- Telegram Bot API
- GORM
- PostgreSQL
- OpenAI API
- Docker
- GitHub

## Project status

The project is currently in the architecture and design phase. The database model, UML diagrams and technical structure are being defined before implementation starts.

## Repository structure

- `docs/architecture/` — architecture decisions and technical notes
- `docs/diagrams/` — ER, UML, sequence and use-case diagrams
- `.env.example` — template for required environment variables

## Academic context

This repository supports the development of the GemeloIA final project and its technical documentation. The implementation will evolve together with the corresponding project report so that the documented architecture matches the real codebase.
